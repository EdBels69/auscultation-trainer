## Быстрый старт

### Шаг 1 — База данных
Зайди в [Supabase SQL Editor](https://supabase.com/dashboard/project/wffsytybxvopwjknfiyb/sql)
и выполни содержимое `SQL_MIGRATIONS.sql` (три миграции по порядку).

### Шаг 2 — Код
Открой `CODEX_PROMPT.md`, скопируй **СИСТЕМНЫЙ КОНТЕКСТ** и вставь в GPT-4.1.
Затем вставляй задачи по одной в порядке: 4 → 2 → 3 → 1 → 6 → 5 → 7 → 8 → 9.

### Шаг 3 — Деплой
```bash
npm run build
# Содержимое dist/ → залить на Бегет через FTP или файловый менеджер
```
