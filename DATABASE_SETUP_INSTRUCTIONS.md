# Инструкция по настройке базы данных Supabase

Проект требует настройки базы данных в Supabase. Выполните следующие шаги:

## Шаги настройки

### 1. Откройте Supabase Dashboard
- Перейдите на https://supabase.com/dashboard
- Войдите в свой проект (или создайте новый, если нужно)
- URL проекта должен соответствовать `VITE_SUPABASE_URL` из файла `.env`

### 2. Создайте таблицы и политики
- В левом меню выберите **SQL Editor**
- Нажмите **New Query**
- Откройте файл `database_setup.sql` из корня проекта
- Скопируйте **весь** содержимое файла
- Вставьте в SQL Editor в Supabase
- Нажмите **Run** (или Ctrl+Enter / Cmd+Enter)

Это создаст:
- ✅ Таблицы: `sounds`, `theory_nodes`, `learning_nodes`
- ✅ Storage buckets: `sounds`, `theory-media`
- ✅ Политики безопасности (RLS) для публичного чтения
- ✅ Индексы для оптимизации запросов

### 3. (Опционально) Загрузите начальные данные
Если хотите иметь начальную структуру теории:
- В SQL Editor создайте новый запрос
- Откройте файл `seed_theory.sql`
- Скопируйте содержимое и выполните

### 4. Проверьте Storage Buckets
- В левом меню выберите **Storage**
- Убедитесь, что созданы buckets:
  - `sounds` (должен быть публичным)
  - `theory-media` (должен быть публичным)

### 5. Перезагрузите приложение
- После выполнения SQL скриптов перезагрузите страницу в браузере
- Ошибки загрузки данных должны исчезнуть

## Устранение проблем

### Если появляются ошибки при выполнении SQL:
1. **Политики уже существуют**: Скрипт использует `DROP POLICY IF EXISTS`, так что можно выполнять повторно
2. **Таблицы уже существуют**: `CREATE TABLE IF NOT EXISTS` предотвращает ошибки
3. **Storage bucket уже существует**: `ON CONFLICT DO NOTHING` предотвращает ошибки

### Если данные все еще не загружаются:
1. Проверьте, что переменные окружения в `.env` правильные
2. Убедитесь, что RLS политики созданы (проверьте в разделе Authentication > Policies)
3. Проверьте консоль браузера (F12) на наличие ошибок
4. Убедитесь, что storage buckets созданы и публичны

## Структура базы данных

### Таблица `sounds`
Хранит аудиозаписи для обучения
- `id` - уникальный идентификатор
- `name` - название звука
- `description` - описание
- `category` - категория
- `position` - позиция прослушивания
- `file_path` - путь к файлу в storage
- `image_url` - URL изображения
- `audiogram_url` - URL аудиограммы

### Таблица `theory_nodes`
Хранит структуру и содержание теории
- `id` - уникальный идентификатор
- `title` - заголовок
- `content` - содержание (Markdown/HTML)
- `is_folder` - является ли папкой
- `parent_id` - родительский узел
- `order` - порядок сортировки
- `category` - категория (cardiac/pulmonary)

### Таблица `learning_nodes`
Хранит структуру обучения
- `id` - уникальный идентификатор
- `name` - название
- `description` - описание
- `parent_id` - родительский узел
- `is_hidden` - скрыт ли узел
- `order` - порядок сортировки
- `node_key` - уникальный ключ узла
- `image_url` - URL изображения
- `audiogram_url` - URL аудиограммы

## После настройки

После выполнения этих шагов приложение должно работать без ошибок загрузки данных. Вы сможете:
- Просматривать разделы обучения (будут пустыми, пока не добавите данные)
- Просматривать теорию (будут пустыми или с начальными данными из seed_theory.sql)
- Входить в админ-панель и добавлять контент
