## Задача 1 — ИИ-помощник v2

### Что не устраивает в текущей версии
- Пустой чат без подсказок: студент не знает с чего начать
- ИИ не знает контекст: что изучал студент, какой был тест
- Промпт без педагогического стиля: ИИ читает лекции вместо диалога
- 10 сообщений истории — лишние токены без пользы
- Устаревший `onKeyPress` (deprecated в React)

### Что делаем

**Edge Function (бек):**
- Новый системный промпт: роль "Сергей Михайлович", сократический стиль,
  обязательный вопрос в конце каждого ответа
- Принимать `context` объект: роль студента, результат последнего теста, раздел
- Динамически достраивать промпт из контекста
- История: slice(-6) вместо slice(-10)
- API: routerai.ru + deepseek/deepseek-v3.2 — без изменений

**AIChatSection (фронт):**
- Контекстная плашка: показывает что ИИ "видит" о студенте
- Chips с быстрыми вопросами: 4 кнопки до начала диалога, меняются в зависимости
  от наличия lastTestResult
- Передача context в каждый запрос
- onKeyDown вместо onKeyPress

**App.jsx:**
- Добавить `lastTestResult` state
- Пробросить `onTestComplete` в TestSection
- Пробросить `userProfile`, `currentSection`, `lastTestResult` в AIChatSection

**TestSection.jsx:**
- Принять prop `onTestComplete`, вызвать после finishTest

### Стоимость токенов
- Запрос до: ~1500 токенов (старая история × 10)
- Запрос после: ~900–1100 токенов
- Экономия ~30–40% при сохранении качества

## Задача 2 — Мобильная адаптация

### Проблемы на мобильном
- Navigation: горизонтальное меню переполняется, пункты вываливаются
- TestSection: 4 статистики в Row span={6} — слишком узкие
- Таблицы: нет горизонтального скролла — контент обрезается
- AIChatSection: кнопка "Отправить" занимает слишком много места
- Общий padding: 40px по бокам на телефоне оставляет мало места контенту

### Что делаем

| Файл | Проблема | Решение |
|------|----------|---------|
| Navigation.jsx | Горизонтальное меню на мобильном | Hamburger + Drawer |
| TestSection.jsx | Статистика результатов | Col xs={12} sm={6} |
| Dashboard.jsx | Таблицы без скролла | scroll={{ x: 'max-content' }} |
| AIChatSection.css | Кнопка большая, layout неудобный | Скрыть текст, sticky input |
| index.css | Нет глобальных мобильных правил | @media блок |
| App.jsx | Content padding | 24px → 12px на мобильном |

## Ожидаемый результат

После спринта студент заходит в ИИ-помощника и видит:
1. Контекстную плашку "Последний тест: 68% · пульмонология · 3 ошибки"
2. Четыре chips: "Разбери мои ошибки", "Почему я путаю?", "Клинический случай", "Как запомнить?"

4. На телефоне: удобное меню, нормальные отступы, кнопка "Отправить" → иконка
